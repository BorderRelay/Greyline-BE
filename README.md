# Greyline-BE

Backend API repository for `Greyline`.

## Stack

- Node.js
- TypeScript
- Fastify
- PostgreSQL

## Purpose

This service is responsible for:

- account auth/session basics
- stash and loadout APIs
- NPC selling
- raid result persistence
- future marketplace APIs
